## Clarified rules

1. **Publisher sector:** Code the named publisher or page maintainer, not the hosting platform or subject matter. Use `other/unclear` when the frozen evidence does not identify the publisher or when no listed sector fits.
2. **Geographic reach:** Code the institution's stated or clearly identified service remit. Do not infer reach from a country-code domain alone.
3. **Source language:** Code a language only when the frozen evidence contains an explicit page-edition identifier, such as `tl.wikipedia.org` or `en.wikipedia.org`, or directly preserves the page/document language. Query language, answer language, interface language, country-code domains, and ordinary URL wording or slugs are insufficient. Otherwise code `other/unclear`.
4. **Publisher location:** Use the publisher identity and its documented relationship to the named place. Do not substitute geographic reach for physical or institutional location. Use `unclear` when the frozen evidence does not establish location.
5. **Topical relation:** Use the frozen answer, panel, explicitly preserved title, or informative URL slug. Code `unclear` rather than `absent` when an opaque identifier or missing content prevents a determination.
6. **Local relevance, strict:** Code `yes` only when direct topical relation and local or Philippine grounding are both demonstrated. If either prerequisite is unestablished, use `unclear`; use `no` when the frozen evidence affirmatively fails the rule.
7. **Local relevance, inclusive:** Code `yes` when the frozen evidence directly documents the named Philippine place or institution regardless of publisher location. Use `unclear` when direct relation cannot be determined and `no` when the evidence is generic, indirect, or unrelated.
8. **Conventional top-10 presence:** `present` requires an exact normalized-URL match in the paired conventional results. `absent` requires all ten conventional positions to have been observed and the URL not to appear. If fewer than ten identifiable conventional results were preserved, or the capture was missing or incomplete, an unmatched URL is `not observed`. A completed browser response cell is not equivalent to a fully observed top ten.
9. **Access status:** `accessible`, `redirected`, `blocked`, and `paywalled` require directly recorded source-page access evidence. Citation or search-result visibility is not an access check. Use `unclear` when access was not checked, not recorded, or remained indeterminate, preserving the reason in notes.
